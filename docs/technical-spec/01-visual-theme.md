# Visual Theme

Direction only — exact colour values/tokens to be decided during implementation
(Tailwind theme config). This captures the intent to design against.

- **Overall palette**: dark, cold, blueish. Not a pure black/neutral dark theme —
  leans blue.
- **Buttons**: a clear, visible outline/border; dark fill inside (outlined-button
  style rather than a solid brightly-filled button).
- **Panels**: smooth, translucent colour fill (semi-transparent, "frosted glass"
  feel) with soft/rounded edges — no hard rectangular borders.
- Applies app-wide: Season Select buttons, Mission Select grid, and all six Mission
  Detail panels should read as one consistent, modern, understated dark-blue UI.

## Resolved

- No existing brand colours/logo to anchor to — free choice of a concrete palette
  within "dark, cold, blueish" during implementation, expected to be revisited once
  there's something visible to react to.
- No formal accessibility target (e.g. WCAG AA) — legibility judged by eye.
